# 若白前端归属图

## 现在三套东西分别是什么

### `public/`
- 当前线上旧版前端的本地镜像
- 原版主题参考来源
- 过渡期不再做大规模重构

### `src-vue/`
- 已冻结的过渡版
- 不再继续当主线开发
- 只保留作参考，后续再迁去旧主题归档

### `frontend-react/`
- 后续唯一正式新主线
- 默认微光主题
- 后续内置原版第二主题

## 工作纪律

- 不在 `src-vue/` 追加新功能
- 不在 `public/` 做大规模视觉重构
- 新的正式前端页面一律落到 `frontend-react/`
- 看旧逻辑可以参考 HTML/Vue，但不要顺手继续在那里开发
