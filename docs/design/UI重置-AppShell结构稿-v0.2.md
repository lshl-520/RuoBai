# 若白 UI 重置 · App Shell 结构稿 v0.2

日期：2026/9/18  
状态：结构重做版。解决 v0.1 与旧 HTML 过于相似的问题。只定结构，不定颜色和材质。

## 一、为什么重做

v0.1 的问题：

- 聊天还是“角色行列表”。
- 角色还是“Hero + 网格”。
- 动态还是“封面 + 头像筛选条 + 信息流”。
- 与旧 HTML 相似度约 90%。

v0.2 的核心变化：**从功能页面中心改成关系中心。**

## 二、五个一级入口

1. **聊天**：关系台，不再只是角色列表。
2. **角色**：角色库，可处理很多角色。
3. **生活**：生活时间线，替代朋友圈式动态。
4. **记忆**：事件与记忆时间轴。
5. **我的**：设置、数据、能力与健康。

聊天室、角色详情、设置、发布、评论属于二级页面或弹层。

## 三、角色多时怎么处理

- 顶部只突出当前角色 / 主陪伴。
- 关系台只展示最近联系，不铺满全部角色。
- 提供搜索：名字、关系、标签。
- 分组：主陪伴 / 常联系 / 全部 / 已归档。
- 支持批量管理：多选、归档、删除（二次确认）。
- 桌面：左列角色切换器，可滚动、可搜索，不与主内容抢空间。

## 四、聊天：关系台

### 手机
- 当前角色：头像、名字、关系、在线、最近说话时间。
- 她今天：最近一条生活 / 对话 / 记忆摘要。
- 快捷入口：进入对话、看生活、看记忆。
- 最近联系：只显示少量角色，全部角色进角色库。
- 搜索角色。

### 桌面
- 左列：角色切换器。
- 中列：当前关系台。
- 右列：她今天的时间轴（对话 / 生活 / 记忆）。

## 五、角色：角色库

- 搜索、筛选、分组。
- 主陪伴区。
- 最近联系区。
- 全部角色区。
- 批量管理入口。
- 桌面：左侧名册 + 右侧角色详情与操作。

## 六、生活：生活时间线

替代旧的“封面 + 头像筛选 + 信息流”。

- 三个筛选：她的生活 / 我们的生活 / 我的记录。
- 按日期和时间排成时间轴。
- 每条记录可来自聊天、照片、语音、动态或评论。
- 可点赞、评论、设置分享范围。
- 桌面：左列时间线，右列这一天的上下文（相关对话、记忆、生活事件）。

## 七、记忆：时间轴

- 顶部：全部角色 / 重要 / 生活事件 / 普通。
- 主内容：按日期从上到下排成时间轴。
- 每张卡：类型、标题、摘要、来源、时间、编辑、删除、置顶。
- 桌面：左列时间轴，右列记忆详情和来源。

## 八、我的

- 资料卡。
- 模板主题 / 灯光模式。
- 通知与主动消息。
- 导出聊天记录。
- 隐私与数据。
- 能力与模型。
- 用量与健康。
- 退出登录放底部。

## 九、硬规则

- 聊天、角色、生活、记忆都不能退回旧 HTML 的列表 / Hero+网格 / 朋友圈结构。
- 角色多时，任何页面都不能靠“全部铺出来”解决。
- 时间轴必须是一条连续线，最后一张卡后不拖尾。
- 危险操作和常用入口分开。
- 结构确认前不进入颜色、材质、动效和三套灯光。
