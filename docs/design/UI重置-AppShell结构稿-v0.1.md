# 若白 UI 重置 · App Shell 结构稿 v0.1

日期：2026/9/18  
状态：结构确认中。只定层级、导航和页面骨架，不定颜色、材质和动效。

## 一、结构原则

- 手机：一个主内容区 + 底部五 Tab。
- 桌面：左侧固定导航 + 主内容区；聊天室使用“会话列表 + 对话”双栏。
- 一级页面只有五个：聊天、角色、动态、记忆、我的。
- 聊天室、角色详情、设置、发布、评论等属于二级页面或弹层。
- 每个页面只有一个主滚动区，页面本身不套第二层滚动。
- 危险操作（清空、删除）永远和常用入口分开，必须有确认。
- 不做公开推荐流、粉丝、排行榜、假统计、订阅墙。

## 二、手机端骨架

```text
状态栏
┌──────────────────────┐
│ 页面标题 / 当前上下文   │
│                      │
│ 主滚动内容区           │
│                      │
└──────────────────────┘
底部导航：聊天 / 角色 / 动态 / 记忆 / 我的
```

- 聊天室：进入后隐藏底部导航，全屏阅读和输入。
- 角色详情：从角色页进入，底部弹层或全屏页。
- 设置类：统一使用底部弹层，避免多层嵌套。

## 三、桌面端骨架

```text
┌──────────┬──────────────────────────────┐
│ 左侧导航   │ 主内容区                       │
│ 聊天       │                              │
│ 角色       │                              │
│ 动态       │                              │
│ 记忆       │                              │
│ 我的       │                              │
└──────────┴──────────────────────────────┘
```

- 聊天室：左列会话列表，右列当前对话。
- 动态 / 记忆：主列内容，右侧只在需要时放详情，不常驻空面板。
- 设置类：居中弹窗或右侧抽屉，不占一级导航。

## 四、页面结构

### 聊天
- 顶部：问候 / 在线数。
- 列表：头像、名字、关系、最近消息、未读、主陪伴标识。
- 操作：点击进入聊天室；长按或更多菜单处理次要操作。

### 角色
- 主陪伴区：一张主角色 Hero。
- 角色区：网格或列表，包含新建入口。
- 详情：进入聊天、编辑资料、主陪伴、自动动态、删除（确认）。

### 动态
- 顶部：标题 + 我的入口。
- 筛选：全部 / 各角色 / 我的。
- 列表：动态卡（作者、正文、图片、点赞、评论、分享）。
- 发布：右下或底部固定入口。
- 评论：展开在当前卡下方，不跳到新页面。

### 记忆
- 顶部：标题 + 角色筛选。
- 列表：重要记忆、普通记忆、生活事件分组。
- 每张卡：内容、来源、时间、编辑、删除、置顶。

### 我的
- 资料卡。
- 设置组：模板主题 / 灯光模式、通知、导出、隐私、能力与模型、用量与健康。
- 退出登录放底部，不和常用设置混在一起。

### 聊天室
- 顶部：返回、角色、模型/思考、搜索、更多。
- 中间：日期分隔、消息、语音、图片、贴纸、思考卡。
- 底部：输入框、语音、通话、图片、贴纸、发送。
- 清空对话移出容易误按的位置。

## 五、完成标准

- 手机五 Tab 和桌面左侧导航关系一致。
- 一级页面、二级页面、弹层归属清楚。
- 页面进入/返回关系不丢失。
- 真实功能没有因为结构简化被删掉。
- 结构确认后才进入颜色、材质、三套灯光和组件状态。
