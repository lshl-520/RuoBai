# OpenDesign 重新生成 Brief v0.1

日期：2026/9/18  
用途：安装并打通 OpenDesign 后，用这份 brief 重新生成新版模板主题。不要把它当成新的产品功能清单；它是“已有功能 + 产品定位 + 五 Tab 熟悉感”的设计约束。

## 一、产品定位

若白是一个私人 AI 陪伴产品，不是公开社交平台。

- 聊天、角色、动态、记忆彼此关联。
- 动态不是朋友圈，而是用户和角色之间的生活痕迹。
- 记忆要能看来源、时间、理由，能纠正、能删除。
- 不编造记忆，不做粉丝、热度、排行榜、假统计、订阅墙。
- 用户不是技术用户，不需要懂提示词、模型或设计术语。

## 二、导航必须保留

保留用户已经熟悉的五 Tab：

1. **聊天**：选择角色、进入对话、最近联系。
2. **角色**：多角色、角色详情、创建/编辑、主陪伴、角色管理。
3. **动态**：用户和角色的生活记录、点赞、评论、发布、分享范围。
4. **记忆**：人工记忆、生活事件、重要程度、来源、编辑、删除、置顶。
5. **我的**：账号、模板主题/灯光、通知、导出、隐私、能力与模型、用量与健康。

不要重新发明导航，不要把一级职责搬去别处。

## 三、允许重新设计的内容

五 Tab 只保留“用户知道每个页面是干什么”的熟悉感。**每个 Tab 内部的内容结构、信息层级、卡片、列表、时间轴、详情层和视觉系统都可以重新设计。**

不得继承旧 HTML、旧 Figma、旧 Pencil、旧 React 的页内布局；也不得继承 v0.1/v0.2/v0.3 的结构稿。

## 四、需要解决的已知问题

- 聊天：模型名/思考入口不要挤坏页头；清空对话不能误按；长历史要有阅读节奏。
- 角色：角色多时不能只靠 Hero + 网格；要有搜索、分组、批量、归档。
- 动态：避免朋友圈式封面 + 头像筛选 + 信息流；要更像生活记录。
- 记忆：要改成时间轴；每张记忆能看来源、时间、理由，可编辑、删除、置顶。
- 我的：模板主题和灯光模式分两层；渠道模型只显示已勾选的模型。
- 桌面和手机都要有清晰布局；桌面不能只是把手机画面放大。

## 五、模板主题与灯光

- 模板主题只保留两种：旧版 HTML/微光（冻结，不再加）、全新设计。
- 灯光模式三套，两种模板共用：微光粉白马卡龙、HTML 旧配色、新配色（月白/雾蓝/暖金方向）。
- 切换模板只换布局/视觉骨架；切换灯光只换颜色、材质、背景光和光效。
- 功能和数据永远不变。

## 六、请 OpenDesign 输出什么

1. 一套新版 App Shell 和五个 Tab 的内部页面结构。
2. 手机端和桌面端的页面骨架。
3. 聊天室、角色详情、发布、评论、设置弹层的层级。
4. 组件规则：导航、按钮、输入、头像、标签、内容卡、时间轴、空状态、加载/成功/失败/禁用。
5. 三套灯光模式的变量建议和状态对比。
6. 一个可点击的高保真原型，先只做“聊天 + 角色 + 动态 + 记忆 + 我的”五个主页面。

## 七、禁止

- 不参考旧布局。
- 不删真实功能。
- 不做公开推荐流、粉丝、排行、假统计。
- 不做订阅墙。
- 不把 AI 生成的整张 UI 图直接裁进页面。
- 不在结构确认前改 React。
