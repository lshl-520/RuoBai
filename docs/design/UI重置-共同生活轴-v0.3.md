# 若白 UI 重置 · 共同生活轴 v0.3

日期：2026/9/18  
状态：从第一原则重做的结构稿。不参考旧 HTML、旧 Figma、旧 Pencil、旧 React，也不参考 v0.1/v0.2 的页面骨架。

## 一、核心模型

只有一个主界面：**你和当前角色共同生活的时间轴。**

聊天、她的生活、我们的生活、记忆、我的记录，不是五个页面，而是同一条轴上的不同事件。

- **角色** = 切换器，不是角色网格页。
- **对话** = 动作，进入对话层，不是一级页面。
- **生活** = 轴上的事件类型，不是朋友圈信息流。
- **记忆** = 轴上的事件类型，不是独立卡片列表页。
- **设置** = 次级抽屉，不占一级入口。

## 二、镜头过滤

同一条生活轴有四个镜头：

1. **此刻**：默认，看最近发生的事。
2. **对话**：只看聊天事件。
3. **生活**：看她的生活、我们的生活、我的记录。
4. **记忆**：看重要记忆和生活事件。

镜头只是过滤，不切换页面，不改变轴的位置。

## 三、角色很多时

- 当前角色显示在顶部，点击打开角色切换器。
- 切换器支持搜索：名字、关系、标签。
- 分组：主陪伴 / 最近联系 / 全部角色 / 已归档。
- 支持批量：归档、删除（确认）。
- 主界面只显示当前角色的生活轴，其他角色不铺满主界面。

## 四、对话层

- 从“和她说话”进入，覆盖生活轴。
- 保留：文本、语音、图片、贴纸、通话、思考、模型、搜索、更多。
- 退出后回到刚才的生活轴位置，不丢上下文。
- 清空对话等危险操作与常用操作分开。

## 五、事件详情

- 点击轴上的事件，打开详情抽屉。
- 显示：类型、时间、角色、来源、关联对话/生活/记忆。
- 可编辑、删除、置顶、设为重要。
- 事件可以来自聊天、照片、语音、动态、评论。

## 六、桌面

- 顶部：当前角色 + 镜头过滤 + 设置。
- 中间：宽生活轴。
- 右侧：当前事件详情和上下文。
- 不使用旧的左侧五 Tab，不把手机画面居中放大。

## 七、功能怎么放回新模型

- 聊天列表：由角色切换器承担。
- 角色网格：由角色切换器承担。
- 朋友圈信息流：由生活轴承担。
- 记忆列表：由记忆镜头 + 事件详情承担。
- 设置：由头像菜单/抽屉承担。
- 首页介绍：保留为未登录介绍页，不进入登录后的主结构。

## 八、硬规则

- 不参考任何旧布局。
- 不默认继承五 Tab、聊天列表、角色 Hero+网格、朋友圈流、记忆卡片列表。
- 结构确认前不进入颜色、材质、动效和 React。
- 如果这版仍被用户判定“像旧的”，继续推翻，不进入视觉阶段。
