# 若白 UI 重置 · 功能地图与信息架构 v0.1

日期：2026/9/18  
用途：这是“全新模板主题”的功能底稿，不是视觉稿，不沿用旧 HTML、旧 Figma、旧 Pencil 的布局。

## 一、先定三条边界

1. 若白是私人 AI 陪伴产品，不是公开社交平台。
2. 动态不是朋友圈热度流，而是用户和角色之间的生活痕迹。
3. 新 UI 只从当前 React 的真实功能和数据推导；旧稿只作历史参考。

## 二、模板主题与灯光模式

### 模板主题：两种
- 旧版：现有 HTML/微光，保留但冻结，不再往上缝新结构。
- 新版：从本功能地图重新设计信息架构和页面布局。

### 灯光模式：三套，两种模板共用
- 微光：粉白马卡龙。
- 旧配色：HTML 时期的粉紫/玻璃感。
- 新配色：建议月白、雾蓝、暖金，和现有两套明显区分。

模板主题只改变布局和视觉骨架；灯光模式只改变颜色、材质、背景光和光效。功能与数据不变。

## 三、页面地图

### 1. 首页 / 介绍页
- 作用：解释若白是什么，不是营销型社交首页。
- 保留：品牌介绍、核心陪伴理念、功能概览、技术边界、计划、预览、联系入口、进入按钮。
- 可保留但后置：背景音乐播放器，避免遮挡手机端主要入口。
- 不新增：订阅、排行榜、假统计、假用户数。

### 2. 登录 / 注册
- 保留：登录、注册、邀请码或首次进入、错误提示、进入 App。
- 视觉目标：安静、可信、不要像商业 SaaS 注册墙。

### 3. App Shell
- 五个主入口：聊天、角色、动态、记忆、我的。
- 全屏页面：聊天室、角色详情/编辑、用量与健康、设置弹层。
- 必须适配：桌面居中、手机安全区、Android 手势条、键盘弹起。

### 4. 聊天列表
- 保留：角色头像、名字、关系/标签、在线状态、主陪伴标识、最近消息、未读提示、进入聊天室。
- 重点：让用户一眼知道“现在可以找谁说话”，不是信息流列表。

### 5. 聊天室
- 顶部：返回、角色头像/名字、模型选择、思考等级、搜索、更多。
- 消息：日期分隔、用户/角色气泡、语音、图片、贴纸、思考卡片、读出来、转文字、重试。
- 底部：输入框、语音、通话、图片、表情/贴纸、发送。
- 安全：清空对话移出容易误按的位置；破坏性操作必须二次确认。
- 关系体验：长历史可分批加载；不让模型名挤坏页头。

### 6. 角色
- 保留：主陪伴角色、角色网格、角色详情、创建/编辑、删除/恢复、主动消息提示、自动动态设置。
- 角色卡需要同时表达：她是谁、你们是什么关系、她现在有没有话想对你说。
- 不把角色做成“卡牌收集”或排行榜。

### 7. 动态 + 评论
- 顶部：动态标题、我的入口、角色筛选。
- 动态卡：角色头像/名字/标签/时间、正文、图片、点赞、评论、分享范围。
- 评论：展开、输入、发送、失败重试。
- 发布：正文、图片、心情标签、发布状态。
- 未来：角色回应、评论联动、用户动态进入生活事件链。
- 边界：不做热度、粉丝、公开推荐流、假评论。

### 8. 记忆
- 保留：角色筛选、人工记忆、添加、编辑、删除、置顶、重要程度、分类、来源和时间。
- 未来：生活事件、自动记忆提示、可追溯来源、可纠正、可删除。
- 重点：让用户一眼看懂“她记住了什么、为什么记住”。

### 9. 我的
- 账号资料、外观与主题、通知与主动消息、导出聊天、隐私与数据、能力与模型、用量与健康、管理后台、关于、退出登录。
- 外观设置拆成两层：模板主题、灯光模式。
- 渠道模型：只显示用户勾选启用的模型，不把抓取到的全部铺出来。

### 10. 用量与健康
- 保留：时间范围、用途筛选、渠道统计、调用事件、Token/耗时/状态。
- 没有真实费用数据时不猜数字。
- 不读聊天正文，不展示隐私内容。

## 四、四条关键用户路径

1. 第一次进入：首页 → 登录/注册 → 聊天列表 → 聊天室。
2. 日常陪伴：聊天列表 → 聊天室 → 文字/语音/图片/贴纸 → 历史继续。
3. 关系闭环：聊天/动态/照片/语音 → 角色回应或评论 → 生活事件 → 记忆 → 未来聊天自然提起。
4. 设置维护：我的 → 模板主题/灯光 → 模型与能力 → 通知/隐私/导出 → 用量与健康。

## 五、必须保留，不能被 UI 删掉

- 文本、语音、图片、贴纸、通话/绘图等真实聊天入口。
- 多角色、角色详情、创建/编辑、主陪伴。
- 动态发布、点赞、评论、分享范围、角色回应。
- 记忆的增删改、置顶、分类、重要程度、来源。
- 渠道、模型、能力开关、密钥、通知、隐私、导出、管理后台。
- 桌面和手机两套布局，不只为截图好看而牺牲功能。

## 六、明确不做

- 公开社交推荐流、粉丝数、热度、排行榜、假统计。
- 订阅付费墙、来源不明的亲密度或虚假互动。
- 为了统一视觉删掉真实功能。
- 继续在旧 HTML/旧 Pencil 稿上缝补当新母版。
