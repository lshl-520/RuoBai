# RuoBai 部署指南

这份文档给第一次部署的人看。按顺序做，不要把真实密钥提交到公开仓库。

## 服务器准备

需要准备：

- Node.js 20 或更新版本。
- MariaDB 或 MySQL。
- 一个域名。
- pm2。

## 安装依赖

进入后端目录：

```bash
cd server
npm install
```

## 配置后端

复制配置样例：

```bash
cp .env.example .env
```

修改 `server/.env`，至少填好：

```env
DB_HOST=localhost
DB_PORT=3306
DB_USER=root
DB_PASSWORD=你的数据库密码
DB_NAME=ruobai
SESSION_SECRET=换成一串很长的随机字符
PORT=3000
CORS_ORIGINS=https://你的域名,https://www.你的域名
BETA_REGISTRATION_ENABLED=true
OPEN_SOURCE_SINGLE_USER=false
```

`server/.env` 是本机私密配置，不要提交。

## 初始化数据库

```bash
cd server
node init-db.js
```

## 启动服务

本地试运行：

```bash
npm start
```

服务器长期运行：

```bash
pm2 start ecosystem.config.js
pm2 save
```

## 反向代理

把域名的请求转发到本机 `3000` 端口，并开启 HTTPS。完成后访问你的域名检查首页是否能打开。

## 邀请码

公开版适合邀请码注册。邀请码写入 `invites` 表，状态使用 `unused`。

## 模型密钥

RuoBai 不内置公共模型密钥。用户登录后，在“我的页”里填写自己的模型密钥。
