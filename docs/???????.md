# 开源与隐私说明

RuoBai 是私人陪伴项目，公开仓库只保存代码、静态资源和安全的部署说明。

## 不应该提交的内容

- `server/.env`
- 数据库备份
- 用户头像、聊天图片、角色立绘和语音缓存
- 手动备份目录
- 测试截图和浏览器快照
- 私人接手提示词、旧工单、体检报告和项目手记
- 任何真实模型密钥、服务器密码或私钥

## 运行时数据

运行时用户数据会保存在数据库和 `user_assets/` 目录。公开仓库只保留 `user_assets/.gitkeep`，不会保存真实用户内容。

## 模型密钥

项目采用 BYOK 模式，也就是用户自己提供模型密钥。代码里不应该写死任何真实供应商密钥。
